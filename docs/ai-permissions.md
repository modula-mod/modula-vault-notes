# Vault Notes AI Permissions

Vault Notes 1.1 requests these permissions as optional:

- `ai.request`
- `ai.stream`
- `ai.structured-output`
- `ai.context.private`

Declining or revoking these permissions disables AI actions only. Ordinary note create, read, update, delete, search, settings, and export workflows remain available.

The update review should explain the data sent to the configured provider, provider availability, and whether provider retention is permitted by host configuration.
