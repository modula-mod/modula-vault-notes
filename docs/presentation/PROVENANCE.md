## Generator

`vault_notes_art.py` is kept here as historical provenance for the current icon and
the superseded generated JPEG cover, rather than as build tooling. It does not produce
the current `cover-candidate.png`. It needs Pillow. Its font helper points at a Linux
Inter font path, but neither generated asset draws text. It writes
`vault-notes-icon.png` and `vault-notes-cover.jpg` (quality 88) to the working directory.

Do not run `mps verify --public` as a claim of final visual approval while these flags remain.
Changing released artwork requires a new release.
