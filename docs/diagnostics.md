# Diagnostics

Vault Notes implements the Standard 1.0 health contract. Diagnostics cover:

- manifest;
- compatibility;
- permissions;
- record schemas;
- data schema;
- runtime;
- search projection;
- settings;
- exports.

Operational counters include note count, folder count, tag count, trashed note
count, version count, search projection lag, failed actions, export failures and
current data schema version. Diagnostics never include note content.
